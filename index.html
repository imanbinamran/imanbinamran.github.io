Claude Code Integration

A personal productivity integration by Amirul

What it does

This application connects Claude Code, an AI coding and productivity assistant, to the owner's own Google account through the Model Context Protocol (MCP). It lets the assistant, when asked by the user:

  • Search, read, label, draft and send Gmail messages
  • View, create, update and respond to Google Calendar events

How it works

The integration runs locally on the user's own computer. Google sign-in uses OAuth 2.0, and access tokens are stored only on that machine. No data is sent to any server operated by this application, and no data is sold or shared with third parties.

Who it is for

This is a personal tool used by its owner to manage their own email and calendar. It is not a commercial service.
